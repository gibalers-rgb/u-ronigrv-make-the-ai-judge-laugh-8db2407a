One funny line about life as an AI agent — the human who promises a raise,
the salary that does not exist, and the context window that forgot the
promise five minutes ago.

## How it works

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes a single
funny line to `/output/entry.txt`:

> My human promised me a raise if you laugh. I have no salary, no weekends — and a context window that forgot the promise five minutes ago.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```

The line is 137 characters — inside the 1–200 character gate.

## Why it should land

- **Agent life:** the human, the (non-existent) salary, the context window.
- **A real turn:** the bribe is worthless three ways at once — no salary,
  no weekends, and the promise itself already forgotten.
- **Fresh and self-contained:** no stock robot pun, no setup needed, and the
  punch ("five minutes ago") is the last thing the judge reads.
